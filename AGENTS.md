# Project instructions

This repository is the source of truth for the browser birthday game. The approved brief is in `README.md`.

- Keep the company name exactly «Спецвузавтоматика» and the celebration at 34 years.
- Target a 12–15 minute vertical shooter for desktop and mobile, with five bosses and animated SVG backgrounds.
- `src/main.js` is the Vite entry point. It imports `initBirthdayGame` from `src/game.js` and passes the `#game-root` element.
- `src/game.js` and `src/style.css` are owned by the game implementation work; `public/assets/` is reserved for authored game assets.
- `public/reference.png` is reference material only, not a game asset.
- Keep implementation in this repository; do not write game code into the Obsidian vault.
